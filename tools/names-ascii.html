Etymology figures, in ASCII

Six shapes for the names page · rendered at the site's real background, colours and font stack · scoping only, nothing built

Everything below is drawn in the page's own font stack (ui-monospace, SF Mono, Menlo, Consolas) at 11px on #04060a, which is what the object pages actually use. So what you see here is what the page would show, including anything your browser gets wrong.

01 The descent rail — narrow, fits the sidebar

For a star, where the name came down one line of transmission and something went wrong on the way. The ✕ is the whole point of the figure: it marks where the meaning was lost, not just where the spelling changed. 46 columns, so it fits the 390px static column.

│ "the bright one on the shoulder"

│ Bat al-Jawzā', which means

│ Bedalgeuze

  Betelgeuse

The rail reads as one continuous descent, which a stack of arrows does not. It also degrades well: an object with only two known stages still looks deliberate rather than stubby.

Arabic is romanised inside the figure and the original script goes in a plain list underneath, where nothing has to line up after it. That is the rule every figure here follows, and it is what row 00 is for.

05 Convergence — when there is no tree

The honest figure, and the one that stops the feature from lying. The Pleiades names share no common ancestor: five traditions named the same cluster independently. Drawing that as a descent would invent a relationship that does not exist, so the arrows point inward instead of down.

   Greek      Pleiades     ─┐
   Arabic     al-Thurayyā  ─┤
   Sanskrit   Kṛttikā      ─┼──▶   ✦ ✦ ✦      one cluster
   Japanese   Subaru       ─┤      ✦ ✦ ✦ ✦    five unrelated names
   Māori      Matariki     ─┘

   No shared root. Five traditions named it five times over, and
   four of them counted seven stars in a cluster where six are
   the most anyone can easily see.

62 columns · also the shape for the Big Dipper

06 The designation ladder — free, and covers all 1,220

Not etymology, but naming, and it needs no prose written at all. stars.json already carries the Bayer letter and constellation for all 2,887 stars; deepsky.json carries the NGC/M number for all 749. Only the right-hand gloss is hand-written, and only for the famous ones. A ladder, not a tree, because these are parallel registers rather than descent.

  Betelgeuse     the name people use
  α Ori          Bayer, 1603 — Greek letters, roughly by brightness
  HR 2061        Yale Bright Star Catalogue
  Crab Nebula    Rosse's sketch, 1844 — the drawing looked like one,
                 the photographs never did
  M1             Messier's first entry, 1758 — the comet that wasn't
  NGC 1952       Dreyer's New General Catalogue, 1888

08 The old descriptions — a second voice on the page

Not a figure, but the other half of the idea. 109 of the 110 Messier objects are already in deepsky.json, so Messier's own 1781 words could land on 109 existing pages. He died in 1817; the text is unambiguously public domain.

Set apart and dated, so it reads as a quotation rather than as the site talking. The site's own sentence does the explaining underneath.

  ┌─ Messier, 1781 ────────────────────── catalogued 12 September ─┐
  │                                                                │
  │  "Nébuleuse au-dessus de la corne méridionale du Taureau,      │
  │   elle ne contient aucune étoile ; c'est une lumière           │
  │   blanchâtre, allongée en forme de flamme de bougie."          │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘

  A whitish light shaped like a candle flame. He was hunting comets
  and logged it so that he would stop mistaking it for one — which
  is why the Crab is number 1 in a catalogue of things to ignore.

M1 · 68 columns · quotation boxed, gloss in the house voice

A dated quotation is also the cleanest answer to the "avoid claims" problem. It is not an assertion about the object, it is a fact about what someone said — true forever regardless of whether he was right. Messier thought this might be a comet. The quote stays correct; the gloss underneath is where the site says what it actually is.

And because Messier consistently calls galaxies nebulae, the distinction not existing yet, roughly forty pages get free historical contrast at no writing cost.

  ┌─ Smyth, 1844 ─────────────────────────── the Bedford Catalogue ─┐
  │                                                                 │
  │  "A double star, with a companion of a fine pale garnet;        │
  │   the contrast of colours is beautifully marked."               │
  │                                                                 │

Same block, second source · a page can carry both, in date order

Two sources in date order is itself the content: you watch the same object get better understood. Smyth died in 1865, also public domain, about 850 objects including the double stars Messier never touched, and nobody else is using him.

09 What this costs

Free: figure 06 for every object on the site, from data already on disk.
Cheap: figures 01 and 05, which are plain text with box-drawing characters both bundled fonts already have.
Needs a decision: whether original scripts appear at all. If yes, they are web-only and end-of-line, and the og.png card silently drops them — the card renders through JetBrains Mono with DejaVu as fallback, and CJK, Hebrew and Devanagari are in neither. Drawing them the way braille is drawn is not an option at that complexity.
Not recommended: a webfont. There is currently no @font-face anywhere in the repo and nothing served from fonts/ over HTTP, so this would be the first, on a site with a page-weight spec.
